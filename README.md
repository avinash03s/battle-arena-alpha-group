# 🎮 Battle Arena

A browser-based shooting game developed as a personal project to explore game development, real-time communication, and backend application development.

## 🚀 Play the Game

**Live Link:** [Play Battle Arena](https://battle-arena-nn45.onrender.com/)

## ✨ Features

- Browser-based shooting gameplay
- Real-time communication using WebSocket
- Java and Spring Boot backend
- Custom game interface built with HTML, CSS, and JavaScript

## 🛠️ Tech Stack

- **Backend:** Java, Spring Boot
- **Real-time Communication:** WebSocket
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Render

## 📱 Enhanced Mobile Gaming Experience

Battle Arena supports Progressive Web App (PWA) installation on compatible Android devices.

- 📲 **Install on Android:** Add the game to your phone's home screen and launch it like an app.
- 🎮 **Immersive Gameplay:** Enjoy a more app-like gaming experience with a dedicated launch icon and a cleaner, potentially full-screen interface.
- ⚡ **Quick Access:** Launch the game directly from your home screen without navigating to the website each time.
- 🌐 **No Play Store Required:** Install from the supported browser when the PWA installation option is available.

**How to play on Android:**
1. Open the [Battle Arena game](https://battle-arena-nn45.onrender.com) in Chrome.
2. Select **Install app** or **Add to Home screen**, if available.
3. Launch Battle Arena from your home screen and enjoy the game!
